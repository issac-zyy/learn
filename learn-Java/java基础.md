# JAVA基础

## JDK/JRE/JVM

jdk是java开发工具包，包含JRE

jre是java运行时，包含jvm

jvm是java虚拟机，Java借助jvm才能实现一次编译，到处运行（相同的程序会编译成相同的字节码

Java9之后的模块系统+jlink工具取代了jre

## 什么是字节码

扩展名为.class的文件就是字节码，不面向任何处理器，只面向虚拟机，解决了解释型语言效率低的问题，又保留了解释型语言可移植的特点

使用Javac把Java文件编译成.class文件，然后解释器把热点代码编译成机器码，其余的代码编程解释器

## 为什么说Java是解释型和编译型并存

JIT在预热时把热点代码编译成机器码，AOT在执行前，把代码编译成机器码（Java17之后不在支持）改善启动速度，减少预热开销

## Oracle JDK和OpenJDK

OpenJDK完全开源，OracleJDK不是完全开源的

OracleJDK在维护期内是免费的，维护期之后，更新是要付费的

OpenJDK不支持LTS服务，OracleJDK每两年一个LTS

## JAVA和c++的区别

Java不提供指针直接访问内存，内存安全

Java是类是单继承，不支持多继承，但是可以多继承接口

Java有gc机制，不需要手动释放内存

C++支持方法和操作符重载，Java只有方法重载

## 移位运算符

```bash
^:异或
<<:左移，高位丢弃，低位补零
>>:带符号右移，低位丢弃，高位补符号位
>>>:无符号右移，
```

高效，处理器有专门的硬件来执行这些移位操作

节省内存，使用一个整数来存储多个布尔值或者标志位（只支持int和long）编译器会把short，byte，char转换成int在进行操作

### 移位的位数超过数值所占有的位数

先对移位的位数求余，然后再进行左移或者右移，对于int，移动32位相当于不移动。long移动64位相当于不移动

## continue，break，return的区别是什么

跳出本次循环，跳出循环体，跳出所在的方法

## 基本类型和包装类型

基本类型的数据存储在栈中，包装类型的对象实例存储在堆中

基本类型占用的内存少

基本类型有默认值，包装类的对象不赋值就是null

==号对于基本类型是比较的是值，对于对象而言比较引用的是否是用一个对象，通常用equals（）或者对应的compare()方法

## 包装类型的缓存机制

Byte,Integer,Long,Short默认创建了【-128,127】的对象，如果给两个变量，赋值为同一个数值，且用的是自动装箱的话，是同一个地址，可以直接用==判断两个变量的地址（但是实践中一律使用equal）

浮点数没有缓存机制

## 什么是自动装箱和拆箱

```bash
Integer i = 10;  //装箱
int n = i;   //拆箱
```

- `Integer i = 10` 等价于 `Integer i = Integer.valueOf(10)`
- `int n = i` 等价于 `int n = i.intValue()`;

## 为什么浮点运算的时候会丢失精度

计算机保存数据是按照二进制保存，小数位经常会无限循环，只能舍弃

## 如何解决精度丢失问题

使用BigDecimal可以精确表示十位数，提供可显式指定精度和舍入规则的运算

## 超过Long的数据应该如何表示

BigInteger使用int[]数组来表示，运算效率会降低

## 成员变量和局部变量的区别

成员变量可以用private,public，static进行修饰，但是成员变量不可以

static修饰的成员变量属于类，未被修饰的属于对象实例

生存时间：成员变量随着对象的创建而存在，随着对象的销毁而消失，局部变量随着方法的调用而存在，方法结束则消失

默认值:如果成员变量没有被赋予初始值，那么会按照默认值赋值（但是final修饰的变量必须显示的赋值）而局部变量不会自动赋值

## 为什么变量有默认值

编译器读取之前必须要确保有值

## 静态变量有什么作用

静态变量只会被分配一次内存，可以节省内存

## 字符型常量和字符串常量的区别

单引号的一个字符，和双引号的若干个字符（可以为0个）

字符常量是一个char值，字符串常量是对String对象的引用，不是暴露的内存地址

占用空间：char值是一个16位的无符号整数，String对象的内存占用则属于JVM的实现细节

## 什么是方法的返回值，有几种类型

无参无返回值，有参无返回值，无参有返回值，有参有返回值

## 静态方法为什么不能调用非静态方法

静态方法属于类，没有对象实例this，非静态方法根本没有被创建，其实也可以直接在静态方法内部创建一个对象，调用被创建对象的方法

## 静态方法和实例方法有何不同

调用方式不同，静态方法可以使用类名.方法名的方式调用，也可以使用对象.方法名的方式

访问成员变量不同，静态方法只能访问静态变量，而非静态方法既可以访问静态变量也可以访问非静态变量

## 重载和重写的区别

重载是根据输入的参数的不同而做出不同的处理

重写是子类继承的时候，输入的参数相同，但是方法要区别于父类，覆写父类的方法

## 什么是可变长参数

允许调用方法的时候，传入不定长度的参数（可以为0个参数），其前面可以有，也可以没有其他参数，但是后面不可以再有其他的参数

遇到方法重载的时候，会优先匹配固定长度的方法

可变参数编译后会被转换成为一个数组

# 面向对象

## 创建对象使用什么运算符，对象实例和对象引用有什么不同

使用new创建对象，堆中用于分配类实例和数组，引用值可以存在局部变量、对象字段、静态字段或者数组元素中，并不一定存放在栈中

一个对象引用可以指向0或者1个对象，一个对象可以有n个引用指向他

## 对象的相等和引用的相等区别

对象的相等用equals（）进行定义

引用的相等用==进行判断

## 如果一个类没有声明构造方法，可以正确执行吗？

编译器会生成默认无参构造，如果已经有了构造方法，编译器就不会生成

## 构造方法的特点是什么？是否可以用@Override

名称和类名完全一样，没有返回值，自动执行，无需调用

不可以覆写，但是可以重载

## 面向对象的三大特征是什么

封装，继承，多态

把成员变量隐藏在对象的内部，不允许外部对象直接访问对象的内部信息，通过方法来读写成员变量

子类对象包含父类声明和实例状态，但是父类的private不是被子类继承，子类也不能直接访问这些成员

子类可以拥有自己的属性和方法，也就是扩展父类

子类可以用自己的方式实现父类的方法

多态不能调用父类中不存在的方法，子类没有重写的方法就调用父类的方法，引用类型变量调用的是哪个类中的方法，只能在运行期间确定

## 接口和抽象类有什么共同点和区别？

共同点：接口和对象类都不能直接实例化，只能被实现或者继承后才能创建具体的对象。

接口和抽象类都可以包含抽象方法，抽象方法没有方法体，必须在子类中实现

区别：接口是为了对类的行为进行约束，实现了某个接口就有了对应的行为，抽象类主要用于代码复用，强调的时候所属关系

一个类只能继承一个类，因为Java不支持多继承，但是一个类可以实现多个接口，一个接口可以继承多个其他接口

接口中的成员变量只能是静态的不可变量，且必须有初始值

抽象类可以有正常的方法和抽象方法，但是接口只有抽象方法

## 浅拷贝，深拷贝和引用拷贝

浅拷贝会在堆上创建一个新的对象，浅拷贝会直接复制内部对象的引用地址

深拷贝在创建完新对象之后，完全复制整个对象，连带着成员变量对象一起复制

引用拷贝是直接用两个引用指向同一个对象

## Object类

Object类是所有类的直接或者间接父亲，因此所有的类都有equals方法

不重写equals的话，就是直接通过==比较两个对象。重写的话应该逐一对比属性

hashcode（）获取哈希码，用于确定对象在哈希表中的索引位置

在hashset中，对hashcode进行简单的变化，然后计算出存储在哪个桶中。如果桶是空的，直接插入数组中，如果桶中已经有其他的元素，HashSet在这个桶对应的链表或者红黑树中逐个用equals进行比较，如果相等，不会再次插入，如果不相等，作为新节点插入到链表或者红黑树中

**为什么不只提供 `hashCode()` 方法？两个对象有相同的 `hashCode` 值，为什么它们也不一定是相等的**

哈希算法也许刚好会让多个对象传回相同的哈希值。越糟糕的哈希算法越容易碰撞

## 为什么重写equals方法必须重写hashcode？

两个相等的hashcode值必须是相等的，如果equals方法判断两个对象是相等的，那么这两个对象的hashcode也要相等

## String,StringBuffer,StringBuilder的区别

String是不可变的，每次修改都会生成新的对象

`StringBuffer` 和 `StringBuilder` 都是可变的，它们在修改字符串时不会创建新对象，而是直接在原有字符数组上进行操作。

`StringBuilder` 与 `StringBuffer` 都继承自 `AbstractStringBuilder` 类，在 `AbstractStringBuilder` 中也是使用字符数组保存字符串，不过没有使用 `final` 和 `private` 关键字修饰

StringBuffer的方法是同步的（线程安全），会带来性能开销

StringBuilder没有同步开销，单线程下有更好的性能表现（10%到15%的性能提升）

## 为什么String是不可变的？

String类中使用final关键字修饰Byte数组来保存字符串，数组的引用是不可变的

可以通过修改字符串来修改字符串，但是String没有提供修改的方法

## 字符串拼接用“+” 还是 StringBuilder?

字符串+拼接被Javac转换成StringBuilder.append（）调用

但是编译器不会创建单个StringBuilder进行复用，循环中拼接字符串会导致创建过多的StringBuilder对象，如果直接使用StringBuilder就不会存在这个问题

## String和Object的equals有什么区别

String的equal是重写过的，会比较字符串的值是否相等，object的equal方法判断两个引用是否指向同一个对象

## 字符串常量池

**字符串常量池** 是 JVM 为了提升性能和减少内存消耗针对字符串（String 类）专门开辟的一块区域，主要目的是为了避免字符串的重复创建

## String s1 = new String("abc");这句话创建了几个字符串对象？

创建1或者2个对象，常量池中不存在abc的话，就要先创建一个放在常量池中，然后创建一个字符串对象，存在堆中，使用abc进行初始化

## String.intern方法有什么作用

是一个本地方法，用来处理常量池中的字符串对象的引用。主要作用是确保字符串引用在常量池中的唯一性

1. **常量池中已有相同内容的字符串对象**：如果字符串常量池中已经有一个与调用 `intern()` 方法的字符串内容相同的 `String` 对象，`intern()` 方法会直接返回常量池中该对象的引用。
2. **常量池中没有相同内容的字符串对象**：如果字符串常量池中还没有一个与调用 `intern()` 方法的字符串内容相同的对象，`intern()` 方法会将当前字符串对象的引用添加到字符串常量池中，并返回该引用。

## String类型的变量和常量做+运算的时候发生了什么？
